## ⚠️ 先看这个：TQQQ 不能长拿

TQQQ 追的是纳斯达克100 指数**每天**涨跌的 3 倍。来回震荡会磨损本金，跌得深了几乎回不来。

| | 1999-03 一次性买入拿到 2026-09 |
|---|---|
| QQQ | **16.5 倍** |
| TQQQ（1999–2010 为模拟值） | **1.9 倍** |

原因是从 2000 年的高点一路跌到 2009 年 3 月，TQQQ 最多跌掉 **99.98%**（光是 2000–2002 年就跌掉 99.95%），跌完就再也涨不回来了。

所以这个项目只把 TQQQ 当成「**大跌时的加码工具**」，而且一定配一个**占比上限**：每次定投时检查一下，TQQQ 超过组合的 20% 就把超出的部分换回 QQQ。

## 规则是什么

网页最上面可以改所有参数。默认是：

| 情况 | 判断（用定投日**前一个交易日**的收盘价） | 这次怎么做 |
|---|---|---|
| 下跌趋势 + 跌得深 | 跌破 200 日均线，且离近一年最高点跌 **≥20%** | 按倍数加码，钱**买 TQQQ** |
| 下跌趋势 | 跌破 200 日均线，跌不到 20% | 按倍数加码，钱买 QQQ |
| 涨太多 | 比 200 日均线高 ≥15% | 投 0.5 倍，买 QQQ |
| 其他时候 | 在均线上方 | 投 1 倍，买 QQQ |

加码倍数（跌破均线之后按回撤分档）：<20% → ×1.5，20–30% → ×2，≥30% → ×3。

**占比上限**：每次定投时检查，TQQQ 市值超过组合的 20% 就把超出的部分换成 QQQ。

## 什么时候卖 TQQQ

网页最上面「什么时候卖 TQQQ」可以四选一，选完整张回测表会跟着重算：

| 规则 | 做什么 |
|---|---|
| **只守占比上限**（默认） | 不择时卖。只在 TQQQ 超过 20% 上限时把超出部分换回 QQQ |
| 涨回 200 日均线就全换回 QQQ | 站回均线上方就把手里的 TQQQ 全部卖掉 |
| 涨回前高附近就减到目标比例 | 离近一年最高点不到 5% 时，把 TQQQ 减到 10% |
| 完全不卖 | 连上限也不管。只用来做对照，**不要真用** |

### 回测（1999-03 至 2026-09，每周 $100，其他设置相同）

| 规则 | 年化 | 最大回撤 | 最惨时 | 平均 TQQQ 占比 | 动手次数 |
|---|---|---|---|---|---|
| **只守占比上限** | **17.68%** | −55.7% | 35% | 15.9% | 240 |
| 涨回均线就全卖 | 14.76% | −48.4% | 36% | 1.6% | 72 |
| 涨回前高附近减到 10% | 16.35% | −52.5% | 35% | 9.2% | 243 |
| 完全不卖 | 24.15% | −77.8% | 17% | 65.7% | 0 |

**关键在「平均 TQQQ 占比」那一列。** 择时卖之所以回撤更小，不是因为卖在了对的时候，而是因为它让你平均只拿着
1.6% 的 TQQQ。同样的效果，把上限从 20% 直接调低就能做到，而且不用频繁动手、不用交那么多次税：

| 只守上限，把上限调低 | 年化 | 最大回撤 | 最惨时 | 平均 TQQQ 占比 |
|---|---|---|---|---|
| 上限 5% | 15.60% | −51.2% | 44% | 4.1% |
| 上限 10% | 16.30% | −52.8% | 41% | 8.1% |
| 上限 15% | 17.00% | −54.2% | 37% | 12.0% |
| 上限 20%（默认） | 17.68% | −55.7% | 35% | 15.9% |

拿「涨回均线就全卖」（平均占比 1.6%，年化 14.76%）去比同样低仓位的固定上限，它并没有更好。
**三种卖法基本落在同一条收益/风险线上——真正的旋钮是上限，不是卖出时机。**

2010 年以后（全真实 TQQQ 数据）四种几乎没差别：20.28% / 19.56% / 20.29% / 20.28%，因为 16 年里上限很少被触发。

## 对照：按风险调杠杆（只在回测里）

回测表里的第三行。每次投一样多，按「波动率目标 30%」调 QQQ、TQQQ、现金的比例：
杠杆 = 30% ÷ QQQ 最近 20 个交易日的年化波动，夹在 0.5–2 倍；2 倍 = 一半 TQQQ 一半 QQQ，1 倍以下拿现金。

1999-03 起每周 $100：年化 21.20%、最大回撤 −50.4%、最惨时剩投入的 52%（大跌才买 17.93% / −55.7% / 35%）。
它收益和最坏情况都更好，但每周都要按配比调仓、一年卖出 5–8 次，所以网站只把它当对照。
计算在 `docs/strategy.js` 的 `leverBacktest` / `leverStatus`，参数和研究过程见项目文档。


## 回测结果（1999-03 至 2026-09，每周投 $100）

> 这是改版前的研究记录（行情到 2026-09-11）。网站现在只显示三行：只买 QQQ、大跌才买 TQQQ、按风险调杠杆（对照），数字每天随行情更新。

| 做法 | 总投入 | 现在市值 | 年化 | 最大回撤 | 最惨时市值/投入 |
|---|---|---|---|---|---|
| 普通定投（只买 QQQ） | $143,500 | $1,717,262 | 15.03% | −51.6% | 42% |
| 综合策略（只买 QQQ） | $180,600 | $2,535,165 | 14.91% | −48.0% | 49% |
| 每次固定 20% 买 TQQQ | $180,600 | $4,008,156 | 17.31% | −57.2% | 42% |
| **大跌才买 TQQQ（本站规则）** | $180,600 | **$4,298,541** | **17.68%** | −55.7% | 35% |
| 稳妥模式（SPY 60/QQQ 30/TQQQ 10） | $143,500 | $1,764,277 | 15.17% | −54.9% | 44% |

**滚动 10 年（每年 1 月开始，共 18 段）**：大跌才买 TQQQ 的年化平均比只买 QQQ 高 **2.52 个百分点**，17 段更高、1 段更低（2013 年那段低 0.24）。

### 三个要记住的结论

1. **「涨回均线就把 TQQQ 卖掉」不划算。** 全样本年化从 17.68% 掉到 14.76%，换来回撤从 −55.7% 变成 −48.4%——但这个交换用「把上限调低」也能做到，而且更省事。超额收益不是来自躲跌，而是来自**大跌时买的那批 TQQQ 一直拿着熬过复苏**。
2. **不封顶最危险。** 同样的买入规则不设上限，年化能到 24%，但最大回撤 −78%，最惨时市值只有投入的 17%，而且 TQQQ 会占到组合的 **91%**——等于赌身家。
3. **「只在大跌买」的价值是保护最坏情况，不是提高平均。** 它平均比「每次固定 20%」还低一点，但 2000 年开始的那 10 年它是 4.5%，固定比例是 3.1%，只买 QQQ 是 4.3%——只有它在最坏的年代没输给纯 QQQ。

### 还要知道的

- **超额收益高度集中在极少数几次抄底。** 最赚钱的那批 TQQQ 是 2009 年 3 月买的，到今天涨了几千倍。少抓住一两次，结果就差很多，所以这个规则很脆弱。
- **2010 年以后（全是真实 TQQQ 数据）差距小很多**：大跌才买 20.28%、只买 QQQ 19.57%，因为 16 年里只触发了 2018、2020、2022 三次。
- 没有算券商手续费、买卖价差、换汇成本和美股分红预扣税（中国居民 10%），再平衡只按 0.05% 估了个点差。
- 过去 27 年美股科技股是超级牛市，以后不一定还有这样的回报。

## TQQQ 的数据是怎么来的

TQQQ 2010-02-11 才成立。这之前的价格是模拟的：

```
TQQQ 当日涨跌 = 3 × QQQ 当日涨跌 + 漂移 / 252
漂移（%/年） = −1.814 − 2.258 × 当年联邦基金利率(%)
```

这两个系数是用 **2010-02 至 2026-09 的真实 TQQQ 数据拟合**出来的（把每年「TQQQ 实际涨跌 − 3×QQQ 涨跌」对当年利率做加权回归，剔除 2020 年这个异常值）。用这个模型重跑 2010 年以后的 16 年半，复利结果和真实 TQQQ 差 **4.5%**。

系数的含义和理论值对得上：`−2.258 × 利率` 就是借来的那 2 倍钱的利息，`−1.814%` 是管理费加上一点点利差。

联邦基金利率年平均值写在 `scripts/update_data.py` 的 `FED_FUNDS` 里。1999–2009 年利率有 5–6%，杠杆成本很贵，所以那一段的误差会比后面大。`data.json` 里每一行都有一个标记，模拟出来的那段标成 0，网页上会写明。

## 部署到网上（大约 15 分钟，只需要做一次）

### 第 1 步：新建一个公开仓库

1. 登录 GitHub 后点右上角 **＋** → **New repository**
2. **Repository name** 填 `qqq-tqqq-dca`
3. 选 **Public**（免费账号的 GitHub Pages 需要公开仓库；你在网页上填的股数和闲钱不会上传）
4. 下面的选项都不要勾，点 **Create repository**

### 第 2 步：上传文件

1. 在新仓库页面点 **uploading an existing file**
2. 把 `qqq-tqqq-dca` 文件夹**里面的内容**（`docs`、`scripts`、`tests`、`workflow`、`README.md`、`requirements.txt`）拖进去——不要拖外面那层文件夹
3. 点页面底部绿色的 **Commit changes**

### 第 3 步：打开 GitHub Pages

**Settings** → 左侧 **Pages** → **Build and deployment → Source** 选 **GitHub Actions**。

### 第 4 步：添加两个工作流文件

`.github/` 是隐藏文件夹，拖拽上传经常会漏掉，所以在网页上单独建：

1. 仓库首页 → **Add file → Create new file**
2. 文件名输入 `.github/workflows/update-and-deploy.yml`（打 `/` 会自动变成文件夹）
3. 把 `workflow/update-and-deploy.yml` 的内容复制粘贴进去，**Commit changes**
4. 用同样的方法建 `.github/workflows/weekly-reminder.yml`，内容复制 `workflow/weekly-reminder.yml`

### 第 5 步：确认跑通

**Actions** → 点「每日更新数据并发布网站」→ 看到绿色对勾就成功了。没有运行记录就点 **Run workflow** 手动跑一次。

然后回到 **Settings → Pages**，页面顶部会显示网址。

## 以后每天会自动发生什么

1. 每个美股交易日收盘后，GitHub Actions 拉 QQQ、TQQQ 和 SPY 的完整历史行情
2. 先跑一遍测试，再检查数据：日期要递增、不能重复、单日涨跌不能离谱（QQQ 超过 25%、TQQQ 超过 75% 就判为异常）
3. 检查通过就写进 `docs/data.json`，补上 2010 年以前的模拟 TQQQ，并重新发布网站
4. 任何一步失败都保留旧数据，网页上会出现黄色提醒，GitHub 也会给你发邮件

## 我的持仓

在首页或「我的记录」填 QQQ / TQQQ 股数（两处共用），首页会算出 TQQQ 占比，超过上限就告诉你卖几股。

## 我的买入记录

记下每次实际买了多少（日期、标的、金额、成交价），网站会算出：

- 按标的分别的股数、均价、现值，和 TQQQ 实际占比
- 总收益率和年化
- **每笔当时规则说该买什么**，以及你有几笔和规则一致

记录只存在这台设备的浏览器里（`qqq-tqqq-trades-v1`），不上传。点「生成备份」会生成一段可以发邮件给自己的文本，
以后「粘贴导入」就能恢复；**原来「纳指100定投」站导出的备份也能直接导入**（那边只有 QQQ，导进来都算成 QQQ）。

## 定投日提醒

`.github/workflows/weekly-reminder.yml` 每个工作日北京时间 20:00 检查一次：

- 今天（美东）是定投日就在 **Issues** 里发一条提醒并 @你，写明这次投多少、**买 QQQ 还是 TQQQ**、QQQ 离最高点跌了多少
- 还会写清楚买 TQQQ 的两个条件各自还差多少；卖出规则触发时，标题上直接标 ⚠️ 该减 TQQQ
- 买 TQQQ 的时候还会提醒你检查占比有没有超上限
- 新提醒发出时上一条自动关闭
- 想马上试一下：**Actions → 定投日提醒 → Run workflow**
- 提醒按 `docs/strategy.js` 最上面的 `DEFAULT_CONFIG` 算。你在网页上改的设置只存在浏览器里，GitHub 看不到；想让提醒也跟着变，就改 `DEFAULT_CONFIG`
